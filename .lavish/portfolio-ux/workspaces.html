This replaces the earlier website-style navigation proposal. The rail, workspace identity, inset background, window frames and edge search remain the interface. Workspace 1 gives writing and career exploration equal weight.

  • Welcome: About + clickable workspace guide.
  • Writing: post list + reader; Focus expands either tile.
  • Experience: career history + selected work from existing content.
  • Contact: direct contact links + personal interests already described on the site.

Try swapping tiles, switching workspaces and returning. Restore layout affects only the active workspace. Search routes to the matching workspace or directly to the example article. Native links support browser Back; shared article links open Writing directly.

Prototype scope: title-bar swapping, tile balance, keyboard-accessible Move, focus/restore, four workspace routes, one complete article, search and unified appearance work. Arrangement lasts for this page session. Arbitrary tiling, all article bodies, final wallpaper pairings and production keyboard bindings remain implementation work.

Select a named workspace in the rail. Welcome explains what each contains.

Drag a window's title bar onto the other window to swap positions. Move does the same thing with a click or keyboard. Focus expands a window; Show all returns to the split.

Restore layout returns the current workspace to its curated arrangement without changing your selected article.

Search anything takes you to a workspace or article. No keyboard commands are needed. In this preview, “/” also opens search when you're not typing, and Escape closes a dialog.
